PROMINENT NOTICE OF MODIFICATIONS (LFM Open License v1.0, Section 4(b)):
This model is a modified Derivative Work of LiquidAI/LFM2.5-1.2B-Instruct created
for the Portal-ML research project. Specifically:
  1. Fine-tuned using a rank-16 bfloat16 LoRA adapter (scripts/train_lfm25_lora.py)
     on 600 synthetic Layer-4 symbolic subgoal planning examples generated by
     scripts/build_layer4_dataset.py (strictly disjoint from evaluation chambers).
  2. Merged the LoRA adapter weights back into the base Lfm2ForCausalLM weights.
  3. Converted and quantized the merged checkpoint from bfloat16 safetensors to
     Q8_0 GGUF format via llama.cpp's convert_hf_to_gguf.py
     (scripts/export_lfm25_gguf.py).
